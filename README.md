# Beliana-Krashi

## Student project starter dashboard

A student-friendly walkthrough for turning a project idea into a reviewed plan, a small first version, and a published website.

- **Open the website:** [Student project starter dashboard](https://bkrashi.github.io/Beliana-Krashi/)
- **View the HTML source:** [index.html](./index.html)

The website link becomes available after GitHub Pages is enabled for this repository. To publish it, open [Settings → Pages](https://github.com/bkrashi/Beliana-Krashi/settings/pages), select **Deploy from a branch**, choose **main** and **/(root)**, and save. GitHub Pages will publish the root `index.html`; the site is public on the internet.
